### Notes from the public run

- The Preview RPC websocket closes mid-submission fairly often (`Normal Closure`). Steps were
  retried until they landed; the contract logic was never the failure.
- A first wallet sync replays the network's full zswap and DUST event history (about 240,000
  events each on Preview, 1.52 million on Preprod). The CLI checkpoints this, so later runs
  resume in seconds.

## Reproduce

```sh
bun install && bun run compact
bun run proof-server
bun run standalone:up
bun run relief deploy
bun run relief setup
bun run relief issue alice Borno 70000 5
bun run relief issue bob Borno 170000 5
bun run relief claim alice
bun run relief claim alice
bun run relief claim bob
bun run relief state
```

For a public network, append `--network preview` or `--network preprod`, and fund the address the
CLI prints from that network's faucet. A fresh wallet replays the network's full zswap and DUST
event history before it can pay fees; the CLI prints progress and checkpoints it, so an interrupted
run resumes instead of starting over.
